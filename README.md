# Telegram-бот: Запись на консультацию

Функции: Меню, пошаговый опрос (Имя, Телефон), сохранение данных в файл requests.json.
Стек: Python, pyTelegramBotAPI (telebot).

Как запустить:

Установите библиотеку: pip install pyTelegramBotAPI
Замените ТВОЙ_ТОКЕН на токен вашего бота.
Запустите: python bot.py

В реальном заказе данные сохраняются в базу данных (SQLite/PostgreSQL) или Google Sheets.
